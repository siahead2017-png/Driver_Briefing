# Как читать эту папку

- `dashboard.html` — открылся сам в начале сборки; можно и двойным кликом.
  Этапы, прогресс, время, что осталось. Обновляется сам, пока сборка идёт.
- `driver-briefing-rework/2026-08-18-brief.md` — твоя изначальная задача, слово в слово. Не редактируется.
- `driver-briefing-rework/manifest.md` — список требований и что с каждым стало.
- `driver-briefing-rework/spec.md` — спецификация.
- `driver-briefing-rework/tickets/` — таски, на которые разбита сборка (если сборка мелкая, их нет).

Если сборка прервалась — скажи агенту «продолжи автопилот», он поднимет состояние отсюда.
