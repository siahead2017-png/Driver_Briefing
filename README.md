# Инструктаж водителя — HEAD, HDLG

Инструмент для проведения инструктажа: шесть блоков, тайминг, отметки о пройденном.
Открывается с телефона, ставится на рабочий экран как приложение.

**Боевой адрес:** https://siahead2017-png.github.io/Driver_Briefing/

Это инструмент **для ведущего**, а не для водителя. Водителю на руки идёт
одностраничная памятка из `dist/`.

---

## Главный принцип

Вслух проговаривается только то, **за что удерживают деньги** или чего нет в телефоне.
Всё остальное — ссылка в базу знаний. Водитель за день слушает несколько инструктажей
от разных служб и не запоминает пересказ того, что и так лежит у него в кармане.

Каждый пункт помечен уровнем:

| Уровень | Значит |
|---|---|
| `say` | Говорить обязательно — деньги, штраф, увольнение |
| `show` | Показать руками, не рассказывать |
| `skip` | Не рассказывать, только назвать раздел базы |

## Что где лежит

| Файл | Назначение |
|---|---|
| `data/briefing.json` | **Весь текст.** Единственный файл для правок |
| `index.html` | Экран инструктажа |
| `print.html` | Печатная версия, оба документа |
| `dist/*.pdf` | Готовые PDF, пересобираются скриптом |
| `assets/js/app.js` | Рендер, чекбоксы, таймер |
| `assets/js/store.js` | Прогресс в localStorage |
| `assets/js/print.js` | Рендер печатных версий |
| `assets/css/styles.css` | Экран, светлая и тёмная тема |
| `assets/css/print.css` | Бумага |
| `tools/` | Скрипты сборки, см. ниже |
| `serve.ps1` | Локальный сервер для просмотра |

## Как править содержание

Всё содержимое — в `data/briefing.json`. Можно править прямо в веб-редакторе
GitHub, не открывая терминал: изменения появятся на сайте через минуту.

Структура пункта:

```json
{
  "id": "bank-no-receipt",          // уникальный, менять не нужно
  "level": "say",                   // say | show | skip
  "text": "Чека нет — три шага",    // заголовок пункта
  "critical": true,                 // подсветить красным (необязательно)
  "money": "500 €",                 // красная плашка суммы (необязательно)
  "checklist": ["шаг 1", "шаг 2"],  // подпункты (необязательно)
  "quote": "Фраза дословно",        // цитата для проговаривания (необязательно)
  "note": "Пояснение для ведущего", // мелкий серый текст (необязательно)
  "link": "docs-bank-receipts",     // id карточки в базе знаний (необязательно)
  "linkTitle": "Банк, чеки: если нету",
  "table": { "head": ["…"], "rows": [["…"]] }   // таблица (необязательно)
}
```

Поле `link` — это `id` карточки из
[базы знаний](https://github.com/siahead2017-png/Driver_Instructions/blob/main/data/instructions.json).
Ссылка соберётся сама. Если карточку в базе переименуют или удалят,
`tools/validate.py` это поймает.

**После правки текста обязательно пересобрать PDF** — иначе бумага разойдётся с экраном.

## Локальный запуск

```powershell
.\serve.ps1
```

→ http://localhost:8000

Сервер нужен: страница читает JSON через `fetch()`, а из `file://` браузер это запрещает.
Двойным щелчком по `index.html` работать не будет.

Альтернатива, если удобнее: `npx serve` — но `serve.ps1` не требует ни интернета,
ни установок, поэтому он основной.

## Скрипты

Все команды — через **`py`**, не `python` (см. CLAUDE.md, там объяснено почему).

```powershell
py tools/validate.py     # проверить briefing.json перед публикацией
py tools/build_pdf.py    # пересобрать оба PDF в dist/
py tools/make_qr.py      # перегенерировать QR (нужно только при смене адресов)
py tools/make_icons.py   # перегенерировать иконки приложения
```

`validate.py` ловит: дубли `id`, опечатки в `level`, кривые таблицы и — главное —
ссылку на карточку, которой в базе знаний больше нет. Битая ссылка иначе
обнаруживается только когда открываешь её при водителе.

## Перенос на другой компьютер

Чтобы просто **пользоваться** — ничего ставить не нужно:

```powershell
git clone https://github.com/siahead2017-png/Driver_Briefing.git
cd Driver_Briefing
.\serve.ps1
```

Ни `npm install`, ни `pip install`. Сайт — чистые HTML/CSS/JS без сборки,
готовые PDF и QR лежат в репозитории.

Чтобы **пересобирать PDF**, нужен Python:

```powershell
py -m pip install -r tools/requirements.txt
py -m playwright install chromium
```

Браузер для Playwright весит ~150 МБ и лежит вне репозитория, поэтому вторая
команда обязательна — без неё `build_pdf.py` упадёт.

## Публикация

GitHub Pages, ветка `main`, папка `/`. Пуш = деплой, сборка занимает около минуты.

Браузер агрессивно кеширует `briefing.json`. Если после пуша видите старый текст —
откройте с `?v=1` в конце адреса.
