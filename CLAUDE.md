# Контекст проекта

Инструмент для проведения инструктажа водителя: шесть блоков, тайминг, отметки
о пройденном. Открывается с телефона. Это инструмент **для ведущего** (отдел учёта),
а не справочник для водителя — водителю на руки идёт памятка из `dist/`.

Боевой адрес: https://siahead2017-png.github.io/Driver_Briefing/

**Язык общения с пользователем — русский.** Интерфейс тоже только русский.

## Место в семье проектов

Три связанных сайта одного владельца, общая дизайн-система:

| Проект | Для кого | Адрес |
|---|---|---|
| `Driver_Instructions` | водителю — база знаний, 64 карточки, видео, калькулятор | siahead2017-png.github.io/Driver_Instructions/ |
| `FuelInstruction` | водителю — где и какой картой заправляться, цены обновляются ежедневно | siahead2017-png.github.io/FuelInstruction/ |
| `Driver_Briefing` | ведущему — этот проект | siahead2017-png.github.io/Driver_Briefing/ |

Локально база знаний лежит в соседней папке `../Dashboard_Instructions` (имя папки
и имя репозитория расходятся — так исторически). `tools/validate.py` проверяет по ней
ссылки; если папки нет, проверка мягко пропускается.

## Главное правило

**Никакой сборки и никаких зависимостей в самом сайте.** Чистые HTML/CSS/JS (ES-модули).

Причины те же, что и в соседних проектах: GitHub Pages отдаёт файлы как есть,
владелец правит контент через веб-редактор GitHub не открывая терминал, проект
не должен протухнуть через год без обновлений npm. Плюс он переносится между
домашним и рабочим компьютером, состав софта на котором заранее неизвестен.

**Не предлагать** React, Vite, Tailwind, бандлеры, npm-пакеты в рантайме.

Node и Python используются **только как инструменты разработки** — генерация PDF,
QR и иконок. Их результаты коммитятся, поэтому на машине без Node/Python сайт
полностью работоспособен; недоступна только пересборка.

## Окружение (важно)

Проверено на домашней машине 01.08.2026:

- **Node.js v24.18.0, npm 11.16.0** — есть.
- **Python 3.12.9** — есть, с `playwright`, `reportlab`, `pillow`, `segno`, `opencv-python-headless`.
- Playwright Chromium 149 установлен и запускается.

**Грабля: `python` — это заглушка Windows Store** (`WindowsApps\python.exe`), она
молча ничего не делает и выводит пустую строку вместо версии. Настоящий интерпретатор —
**только `py`** (`...\Programs\Python\Python312\python.exe`). Все команды в документации
и все инструкции пользователю писать через `py`.

Вывод кириллицы в консоль ломается на cp866 — запускать скрипты как `py -X utf8 tools/….py`,
иначе в выводе будет каша (на сам результат работы это не влияет).

**Windows PowerShell 5.1 читает `.ps1` без BOM как ANSI** — кириллица в скриптах ломает
парсер. `serve.ps1` держим **ASCII-only**. На этом уже падал такой же файл в соседнем проекте.

Локальный сервер обязателен: страница читает JSON через `fetch()`, из `file://` запрещено.

**Останавливая `serve.ps1`, не убивать процесс по владельцу порта** — `Get-NetTCPConnection`
покажет PID 4 (System), потому что префикс регистрируется в HTTP.sys ядра. Искать нужно
процесс `powershell.exe` с `-File …serve.ps1` в командной строке. И осторожно с фильтром
по `CommandLine`: слишком широкий шаблон совпадёт с самой командой поиска, и она убьёт себя.

## Модель данных

Всё содержимое — `data/briefing.json`. Два независимых раздела:

- `blocks[]` — сценарий для ведущего. Блок → `items[]`, у пункта обязательны
  `id`, `level` (`say`/`show`/`skip`), `text`; остальное необязательно.
- `cheatsheet` — памятка водителю. **Отдельный текст, не выводится из `blocks`:**
  у неё другой адресат, поэтому обращение на «ты» и другие формулировки.
  Дублирование здесь осознанное.

`link` / `links[].id` — идентификаторы карточек базы знаний, URL собирается из `kbBase`.

## Как проверять изменения

```powershell
py -X utf8 tools/validate.py
py -X utf8 tools/build_pdf.py
.\serve.ps1
```

Проверки, которые уже ловили проблемы:

- **Сценарий не влезает в 2 листа** — влезает в 3, это принято осознанно.
  `break-inside: avoid` на блоке (`.blk`) раздувал документ до 4 листов, потому что
  каждый блок уезжал на новую страницу. Разрыв запрещён только на уровне пункта (`.row`).
- Русские склонения счётчиков (`plural()` в `app.js` и `print.js`) — был баг «32 минут».
- Отсутствие горизонтального скролла на 375 px. Таблицы обязаны скроллиться
  внутри `.tbl-wrap`, а не растягивать страницу.
- Прогресс и таймер переживают перезагрузку; «Сбросить» чистит и то, и другое.
- QR должны **декодироваться в печатном размере** (25 мм ≈ 95 px), а не просто рисоваться.
  Проверять `cv2.QRCodeDetector` по скриншоту, а не на глаз.
