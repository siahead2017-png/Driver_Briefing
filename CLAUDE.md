# Контекст проекта

Инструктаж водителя: шесть тем плюс вступительная «Рамка» (блок `num: 0`),
тайминг на 30 минут, отметки о пройденном. Открывается с телефона.
Инструмент **для ведущего** (отдел учёта), а не справочник для водителя —
водителю на руки идёт памятка из `dist/`.

**Инструктаж ведёт не только владелец, но и его коллеги** (02.08.2026). Отсюда
два следствия: в сценарии не должно быть личных имён (есть слоты `{имя}` /
`{должность}`), а логика «почему такой порядок, что значат цвета» живёт в
разделе `guide`, а не в голове у автора.

Боевой адрес: https://siahead2017-png.github.io/Driver_Briefing/

**Язык общения с пользователем — русский.** Интерфейс тоже только русский.

## Место в семье проектов

| Проект | Для кого | Адрес |
|---|---|---|
| `Driver_Instructions` | водителю — база знаний, карточки, видео, калькулятор | siahead2017-png.github.io/Driver_Instructions/ |
| `FuelInstruction` | водителю — где и какой картой заправляться, цены ежедневно | siahead2017-png.github.io/FuelInstruction/ |
| `Driver_Briefing` | ведущему — этот проект | siahead2017-png.github.io/Driver_Briefing/ |

Локально база знаний — соседняя папка `../Dashboard_Instructions` (имя папки и
репозитория расходятся, так исторически). `tools/validate.py` проверяет по ней
ссылки; нет папки — проверка мягко пропускается.

**Два «виртуальных экрана» базы подключаются через `href`, а не `link`.**
`#/bans` («Запреты движения») и `#/feedback` («Написать в офис») — не карточки,
а собственные экраны приложения. `kbBase` дописывает `#/item/` и увёл бы ссылку
в никуда. `validate.py` их по той же причине не проверяет — открывать руками.

## Главное правило

**Никакой сборки и никаких зависимостей в самом сайте.** Чистые HTML/CSS/JS
(ES-модули). GitHub Pages отдаёт файлы как есть, владелец правит контент через
веб-редактор GitHub не открывая терминал, проект не должен протухнуть через год
без обновлений npm, и он переносится между двумя компьютерами с разным софтом.

**Не предлагать** React, Vite, Tailwind, бандлеры, npm-пакеты в рантайме.

Node и Python — **только инструменты разработки** (PDF, QR, иконки). Результаты
коммитятся, поэтому без Node/Python сайт работает; недоступна лишь пересборка.

## Окружение (важно)

- **`python` — заглушка Windows Store**, молча ничего не делает. Настоящий
  интерпретатор только **`py`**. Все команды писать через `py`.
- Кириллица в консоли ломается на cp866 — запускать `py -X utf8 tools/….py`.
- **PowerShell 5.1 читает `.ps1` без BOM как ANSI**, кириллица ломает парсер.
  `serve.ps1` держим **ASCII-only** (на этом уже падал файл в соседнем проекте).
- Локальный сервер обязателен: страница читает JSON через `fetch()`.
- `playwright`/`pypdf`/`segno` не предустановлены: `py -m pip install -r
  tools/requirements.txt` + `py -m playwright install chromium`.
- **Останавливая `serve.ps1`, не убивать процесс по владельцу порта** —
  `Get-NetTCPConnection` покажет PID 4 (System), префикс регистрируется в
  HTTP.sys ядра. Искать `powershell.exe` с `-File …serve.ps1`. Осторожно с
  фильтром по `CommandLine`: широкий шаблон совпадёт с самой командой поиска.

## Модель данных

Всё содержимое — `data/briefing.json`, четыре независимых раздела:

- `blocks[]` — сценарий. Блок → `items[]`; у пункта обязательны `id`,
  `level` (`say`/`show`/`skip`), `text`.
- `guide` — «Как вести инструктаж», онбординг для коллеги. **Верхнего уровня,
  не элемент `blocks[]`** — иначе попал бы в счётчик пунктов, прогресс-бар,
  сумму минут и печатный сценарий.
- `cheatsheet` — памятка водителю. **Отдельный текст, не выводится из `blocks`:**
  другой адресат и другие формулировки, дублирование осознанное.
- `contacts` — контакты офиса, уходят водителю PDF по QR. **Собирается здесь,
  а живёт на `Driver_Instructions`:** `build_pdf.py` копирует файл в
  `../Dashboard_Instructions/assets/docs/`, `links.contacts` указывает туда же.
  Причина: при сканировании QR телефон показывает домен до открытия, и
  «Driver_Briefing» водителю ничего не скажет, а «Инструкции» он знает.

`link` / `links[].id` — карточки базы знаний, URL собирается из `kbBase`.
**Слоты `{…}`** в `text` и `quote` — то, что ведущий подставляет голосом;
рендерит `slots()` в `assets/js/util.js`, экранирование идёт ДО подстановки.

## Как проверять изменения

```powershell
py -X utf8 tools/validate.py    # структура данных и ссылки
py -X utf8 tools/build_pdf.py   # PDF + счётчик листов
py -X utf8 tools/measure.py     # на сколько мм документ не влезает
.\serve.ps1
```

Грабли, которые уже ловили:

- **Памятка водителя обязана быть ОДНИМ листом** — её отдают на руки, это
  единственный жёсткий лимит. Срывалась дважды (02.08 и 12.08.2026). Кегль
  9.5pt и QR 25 мм не трогать: **резать контент, а не шрифт**. Сокращать слова
  внутри строки бесполезно — высоту меняет только слияние или удаление строк.
- **Сценарий занимает 5 листов** (3 → 4 → 5 по мере роста содержания); лимит в
  `build_pdf.py` поднимался вместе с ним, это плата за содержание. `break-inside:
  avoid` на блоке (`.blk`) раздувал документ ещё сильнее — каждый блок уезжал на
  новую страницу; разрыв запрещён только на уровне пункта (`.row`).
- **Что видит владелец, если сломает JSON.** Он правит файл в веб-редакторе
  GitHub, и вероятная ошибка — не синтаксис (его подсветит GitHub), а
  удалённый ключ: JSON валиден, страница падает. `checkShape()` в `app.js` и
  `validate.py` ловят это и называют ключ по имени. Проверять негативным тестом.
  **`guide` намеренно вне `checkShape()`**: без него инструктаж вести можно,
  ронять всю страницу неправильно — но и молчать нельзя (до 12.08.2026
  `renderGuide()` просто выходил по `return`, и пропажу заметил бы только
  коллега, которому нечего читать). Теперь на месте карточки объяснение.
  Тот же приём для любого «необязательного» раздела: не падать, но не молчать.
- **Статический `import` не наследует `?v=`** от импортирующего модуля, и правки
  приезжали из кэша PWA. Поэтому `store.js`/`util.js` подключаются динамически:
  `await import('./store.js' + new URL(import.meta.url).search)`. Новый общий
  модуль подключать так же.
- **`styles.css`, `app.js`, `print.css`, `print.js` грузятся с `?v=` через JS**,
  не обычным `<link>`/`<script src>` — иначе на телефоне (особенно PWA) ещё
  долго открывается старая версия. `briefing.json` — то же через `fetch()`.
  Правки не видны — сперва проверить `curl`, что на Pages уже новая версия.
- **`overflow: hidden` на предке ломает `position: sticky` у потомка**: любой
  overflow кроме `visible` делает предка границей стика, и если сам предок не
  скроллится (высота `auto`, как `.block`), потомок не цепляется за прокрутку.
  На этом ловился прилипающий `.block__head` — overflow убран с `.block`, углы
  скругляются точечно на `.block__head`/`.block__body`.
- **Кнопка «Печать / PDF» (`window.print()`) — не источник финального PDF.**
  При включённых в Chrome колонтитулах браузер допечатывает URL и дату поверх
  контента, CSS это не контролирует. Раздавать `dist/*.pdf` от `build_pdf.py`.
- QR должны **декодироваться в печатном размере** (25 мм ≈ 95 px) — проверять
  `cv2.QRCodeDetector` по скриншоту, а не на глаз.
- Русские склонения счётчиков (`plural()` в `util.js`) — был баг «32 минут».
- Отсутствие горизонтального скролла на 375 px: таблицы скроллятся внутри
  `.tbl-wrap`, а не растягивают страницу.
- Прогресс и таймер переживают перезагрузку; «Сбросить» чистит и то, и другое,
  долгое нажатие на таймер — только время.

## Правило двух телефонов (02.08.2026)

- **Рабочий** (закреплён за тягачом, уезжает с машиной): WhatsApp с офисом,
  SMSVinjetes, NESTE, CIRCLEK, закладка eurovignettes.eu — всё, чем платят за
  счёт компании. Контакты офиса предустановлены. Интернет 20 GB на всё.
- **Личный**: «HEAD, HDLG Инструкции» — **обязательно, условие допуска**.
  «Заправки» — по желанию. Рабочий телефон водитель сдаёт вместе с машиной, а
  база знаний нужна ему и на пересменке, и при смене машины.

Правя блок 1 или памятку, не сползать обратно к «рабочему телефону».

## Открытые хвосты

1. Правила «450 л + 100 л реф», «не более 200 л на въезде в Испанию» и запрет
   заправки в шести странах взяты с сайта «Заправки». Контент правится в
   Google-таблице и мог измениться — перед проведением сверить.
2. **Тайминг: план 30 минут, дважды вживую вышло дольше** (аудиозаписи 12.08 и
   18.08.2026 — второй раз почти теми же местами, несмотря на то что после
   первой записи в сценарий уже добавили заметки против растягивания). 18.08
   пересобран заново: лимиты по калькулятору/боксам/EUROVIGNETTE перенесены из
   `note` (бледный текст, легко проскочить взглядом) в основной `text`/`checklist`
   каждого пункта — заметки не работали именно потому, что были неглавным
   текстом. Замер вживую после этой пересборки **снова не делался** — та же
   открытая точка, что и после 12.08. Куда утекало время — раздел гида «Почему
   выходит 40 минут».
3. Не подтверждено: что делать, если инспектор намекает на взятку сам
   (`red-bribe`). Номер разблокировки Universal записан **по роли**
   («руководитель отдела учёта»), не по имени — чтобы фраза не ломалась у коллеги.

Подтверждено аудиозаписью 12.08.2026 (раньше было «по здравому смыслу»): состав
девяти карт — восемь топливных плюс банковская; датчики уровня топлива стоят на
всех тягачах и прицепах, сверяется каждая транзакция.

**18.08.2026 — вторая пересборка, по интервью с владельцем (не только по
аудиозаписи).** Изменения:

- Было 7 блоков (0–6), стало 6 (0–5): «Красная линия» (бывший блок 5) слита
  внутрь блока 3 — на обеих записях разговор про чек тягач/прицеп и датчики
  шёл естественно внутри разговора про карты, отдельным блоком не получалось.
- Блок 3 переименован в «Заправки и карты». **Владелец сознательно отменил**
  решение от 12.08 «не перечислять карты по одной, только смотреть в Заправках»
  — по картам нюансы не всегда очевидны водителю. Новый формат: таблица по
  одной строке на карту, сгруппированная «В Европе» / «В Латвии», плюс
  отдельный пункт CROSSCHEM (AdBlue) — у него нет PIN, это ловушка, а не
  «где платить».
- «Что сделать после» (памятка, напоминание про базу знаний и про «Написать в
  офис») теперь дублируется как видимые пункты в конце блока 5 — раньше жило
  только в `guide`, читалось ведущим один раз до первого инструктажа и никогда
  не появлялось на экране во время самого разговора. Заодно убрана фраза
  «после меня инструктаж отдела контроля» — она не всегда верна, порядок
  бывает обратный.
- Живую запись 18.08 вёл владелец лично; коллеги пока не ведут — вопрос
  «работает ли это для чужого ведущего» остаётся открытым до того, как кто-то
  ещё начнёт вести инструктаж (правило безличности сценария уже соблюдается).
